# Code of Conduct

Arkive follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and constructive. Assume good intent, and critique code and ideas rather than people.
- Harassment, personal attacks, discriminatory language and publishing someone's private information are not acceptable.
- This applies to every project space: issues, pull requests, discussions and any other channel used for the project.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainer through
[GitHub's report-abuse tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or by contacting [@islamdiaa](https://github.com/islamdiaa) directly. Reports are handled confidentially.

## Enforcement

The maintainer may remove, edit or reject comments, commits, issues and other contributions that break this code of conduct,
and may temporarily or permanently block a contributor for behaviour they consider inappropriate, following the
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) of the
Contributor Covenant.
